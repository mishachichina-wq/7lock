7lock iOS 8 — Layout Editor (експериментальна версія)

1. Замініть файли у GitHub репозиторії вмістом цього архіву та зберіть через Actions.
2. Увімкніть Time Bar (Disable Time Bar = OFF).
3. На екрані блокування затисніть область годинника на 1.5 секунди.
4. Виберіть Clock / Date / Unlock / Camera.
5. Рухайте Horizontal, Vertical, Size — зміни застосовуються одразу.
6. Save зберігає значення; Close закриває без збереження (але поточний вигляд лишається до оновлення). Reset повертає стартові значення; для їх збереження натисніть Save.

УВАГА: експериментальний редактор, не перевірений на пристрої чи в GitHub Actions.
Редактор не змінює системний замок, повідомлення чи графічні ресурси iOS 8.
Якщо твік нестабільний, поверніться до попередньої робочої збірки.
